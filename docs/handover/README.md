# SFSC 历史交接文档归档

本目录是早期“仅服务端交付包”的历史交接草稿。当前项目已经演进为客户端、服务端、协议合同和发布包共同维护的产品化工程，因此本目录不再作为权威说明来源。

请以以下文档为准：

- `docs/SOFTWARE_DESIGN_SPEC.md`：当前软件设计说明书。
- `docs/INTERFACE_CONTRACT.md`：客户端/服务端接口与协议合同，双端对齐的唯一基线。
- `docs/DEPLOYMENT_AND_MIGRATION_GUIDE.md`：当前部署、迁移、预检和烟测说明。
- `docs/PROJECT_HANDOFF.md`：当前项目交接说明。
- `README.md` 与 `client/README.md`：当前运行、打包和客户端说明。

本目录中的文件只保留历史索引用途，不能用于判断当前 API、错误码、打包范围或部署流程。
