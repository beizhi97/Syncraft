# 信息架构与关键用户流程

## 客户端信息架构

### 1. 同步

- 当前任务：本地文件夹、方向、远端目标、计划
- 当前状态：准备、预览、同步中、停止中、完成、失败
- 主操作：预览并开始 / 停止同步 / 查看处理办法
- 次级操作：保存任务、切换任务

### 2. 历史

- 最近运行：成功、失败、已停止、未知、冲突
- 搜索与状态筛选
- 单次运行详情：触发方式、时间、传输、冲突、错误和恢复动作

### 3. 设置

- 连接：导入或替换 T-key、Profile 摘要、心跳状态
- 同步默认值：并行文件、单文件线程、带宽、计划
- 组件与隧道：sing-box、rclone、启动/停止
- 诊断：协议、发布包、本地状态、日志、脱敏诊断包

### 4. 首次使用

- 独立页面完成导入 T-key → 检查连接 → 选择文件夹 → 创建第一个任务
- 不把安装说明长期留在日常工作台

## 服务端信息架构

### 1. 概览

- 服务健康、配置是否已应用、存储是否可用
- 在线/同步中/异常设备
- 需要处理的兼容性、仓库或配置问题

### 2. T-key

- 选择设备、仓库和有效期
- 生成一次性 T-key
- 默认遮蔽、显式复制、测试兑换
- 结果与失败恢复建议

### 3. 设备

- 密集表格：名称、在线、启用、同步、兼容性、仓库、最近心跳
- 筛选、搜索、按需查看详情
- 停用/删除放入行级高级操作并二次确认

### 4. 基础设置

- VLESS / REALITY 配置与应用状态
- S3 / MinIO 连接参数
- 同步仓库生命周期
- 脱敏配置预览和受控应用

## 客户端关键流程

1. 首次启动 → 进入独立导入页。
2. 粘贴完整 T-key 或导入 URI → 校验并兑换 → 显示脱敏 Profile 摘要。
3. 检查组件、心跳和协议兼容性 → 若失败，显示原因和下一步。
4. 选择本地文件夹 → 选择同步方向和计划 → 保存任务。
5. 预览目标、删除风险和兼容性影响 → 必要时页面内确认。
6. 开始同步 → 显示阶段、进度、当前文件和停止操作。
7. 完成后写入历史；失败不隐藏错误码，并给出重试或诊断入口。
8. 关闭窗口 → 托盘后台继续运行；主界面下次打开恢复当前状态。

## 服务端关键流程

1. 管理登录 → 获取健康、版本和协议摘要。
2. 检查“配置就绪度” → 修复 VLESS、存储或未应用配置。
3. 建立并启用同步仓库。
4. 创建或选择设备 → 为设备和仓库生成一次性 T-key。
5. 复制完整 T-key 或导入 URI → 交给客户端；测试兑换后明确标记不可再用。
6. 在设备页监控在线、同步和兼容性 → 进入详情排查异常。
7. 危险操作必须说明影响对象、要求确认文本，并显示执行结果。
