# Syncraft 当前 UI/UX 问题清单

## 客户端

1. 首次导入和日常同步曾共用同一视图；现在应保持独立导入页，日常界面只呈现当前任务与下一步。
2. 设置、历史和同步状态不得以固定成功、日期、设备或文件数量模拟运营数据；未绑定接口时必须显示加载中、暂无数据或等待检测。
3. 客户端只能显示已授权的同步内容；不得输入、搜索、猜测、加入或枚举 Sync ID，也不得暴露路径、bucket 或 prefix。
4. 停止、失败、离线和协议不兼容必须有明确影响与恢复动作，不能只以颜色区分。

## 服务端管理控制台

1. 概览、设备和基础设置需从管理状态接口加载，不应保留固定健康、容量、在线设备或同步结果。
2. SyncKey 生成必须选择管理员已创建的同步空间和设备，提交 `syncSpaceId` 与 `requestedRole`，并显示真实响应。
3. 危险配置变更须保留页面内确认；敏感值默认遮蔽。

## 不变约束

- 不改变 API 路径、枚举、错误码含义、SyncKey 流程或关键 DOM id。
- 不在任何原型中出现真实 Token、SyncKey、私钥、设备名、仓库名或本机路径。
