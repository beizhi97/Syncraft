# SFSC 基础设置页 · Creative Director 评审

## 什么是“好看的设计”

- **受众**：需要配置 VLESS、存储连接和同步仓库的 SFSC 管理员。
- **业务目标**：快速判断配置是否可用、哪些修改尚未应用，以及下一步应执行什么操作。
- **品牌气质**：安静、可信、克制的 Windows 运维工作台；强调长期使用，不追求展示感。
- **风格参考**：Cursor、GitHub Desktop 与 Windows 生产力工具的紧凑层级；借鉴其秩序感，不复制品牌外观。
- **信息密度**：服务端保持高密度，但每个区域只表达一个配置主题；状态与动作紧邻。
- **色彩**：暖灰中性色承载 90% 画面，橙色只用于当前主操作；绿色、琥珀和绯红分别表示正常、待处理和危险。
- **字体**：Segoe UI Variable / Microsoft YaHei UI；标题 24px，区块标题 15–16px，字段与状态 12–14px。
- **动效**：配置页不需要装饰动效；只保留按钮、模态框和状态反馈的短时过渡。
- **素材**：无需插画、生成图片或图标墙；真实表单、状态和脱敏配置就是页面的视觉主体。

## 不能出现的模板感

- 营销式标题和功能介绍副标题。
- 大面积渐变、发光球、装饰插画和无意义图标。
- 大量等权卡片或每个标题旁都放图标。
- 为填充空间而添加的统计数据、说明文字和空状态。
- 在产品页面暴露“原型”“评审”“实现说明”等设计过程语言。

## 诊断

截图中的表单与状态层级已经可靠，主要问题是“基础设施”过于工程化，且标题下的小字重复解释了下方已经清楚呈现的 VLESS、存储连接与同步仓库。页面头部因此更像说明页，而不是直接可操作的管理工具。

## 风格方向

采用“安静运维工作台”：保留暖灰背景、细边框、紧凑表单和单一橙色主操作；将页面、顶栏和侧栏统一命名为“基础设置”，删除标题下说明，让控件和状态本身承担解释。

## 资源选择

- **主资源**：`DESIGN.md`，继续使用已验证的 SFSC Token 和桌面密度。
- **结构资源**：`server-infrastructure.html`，保留现有布局、交互与脱敏字段。
- **视觉证据**：标注截图，用于定位标题区和侧栏命名问题。
- **未使用生成素材**：该页面是结构化管理界面，图片生成、Lottie、3D 或营销模板都会降低信息效率。
- **未引入外部组件库**：原生 HTML/CSS/JS 已能满足当前交互，新增依赖没有收益。

## 具体落地

1. 文档标题、顶栏、页面标题与侧栏统一为“基础设置”。
2. 删除页面标题下方的小字。
3. 将 VLESS、存储连接、同步仓库整理为三个可切换的设置标签页；VLESS 首屏保留另外两类设置的状态摘要和直达入口。
4. 存储连接已提供可编辑表单、连接检查和保存反馈；同步仓库已提供状态表格与行级操作。
5. Public Key、Private Key、Access Key 与 Secret Key 默认遮蔽，显示密钥必须由用户显式触发。
6. 应用 VLESS 配置继续使用页面内确认，明确重启影响和在线设备状态。
7. 启动页、信息架构和状态矩阵同步采用“基础设置”；保留 `server-infrastructure.html` 文件名和链接，避免破坏导航合同。
8. 不修改全局 CSS、设计 Token、API、生产枚举或同步行为。

## 验证标准

- 首屏直接出现配置控件与状态，不像介绍页。
- 页面中不再出现“基础设施”旧称。
- 敏感字段继续默认遮蔽。
- 1280×720 与 1440×900 下标题区不挤占工作区。
- 页面无新增模板感、装饰性素材或内部设计说明。

## 落地验证

- **命名**：用户可见页面、启动页和配套文档均使用“基础设置”；旧称只保留在本评审的诊断上下文与既有文件名中。
- **首屏层级**：标题区仅保留 24px 页面标题，紧接设置标签和 VLESS 配置状态，没有重复说明段落。
- **交互**：三个标签支持点击、左右方向键、Home、End；VLESS 摘要中的“编辑连接”“管理仓库”可直接切换到目标标签。
- **敏感信息**：VLESS 密钥以遮蔽文本呈现；存储密钥使用密码输入并以“保留当前值”为占位提示。
- **低高度适配**：共享样式在高度小于 760px 时收紧内容顶部、标题区和面板内边距，覆盖 1280×720 的首屏工作区需求。
- **影响范围**：本轮仅调整基础设置实现相关文档和启动页可见命名，没有修改共享 Token、生产代码或协议行为。
