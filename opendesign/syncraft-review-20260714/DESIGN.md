# Syncraft 设计系统

## 设计姿态

Syncraft 是明亮、紧凑、可信的 Windows 同步工具。产品首屏直接呈现任务、状态和下一步，不使用营销文案、装饰插画、渐变背景或大面积品牌色。冷白工作面与青蓝操作色让客户端和服务端保持轻快一致；客户端优先可理解性，服务端优先信息密度。

## 交付前视觉收口（2026-07-14）

先定义审美目标与约束：把界面收成一款克制的 Windows 常驻工具——以任务、状态和下一步为视觉骨架；用留白、细分隔线和字级，而非卡片堆叠、渐变或光晕建立层级；错误必须说明影响和下一步；不牺牲同步 ID / SyncKey 的安全边界。随后核对并复用现有页面、`prototype.css`、`prototype.js` 与既有 CSS 图标，不引入外部图片、插画或新图标库。此次没有需要产品负责人选择的分支，因此未生成 question-form。

## 服务端管理 UI 第二轮（2026-07-16，本地修订基线）

审美目标：真实的自托管系统管理控制台，优先异常、扫描效率和操作反馈；深色导航保持静默，浅色工作区以表格、分隔线和单一主操作组织信息。禁止渐变、光晕、教程式副标题、等权仪表盘卡片和重复的“正常”提示。每个可见句子只说明当前状态、异常影响或下一步。

资源与合同审计：本次复用正式 `public/index.html`、`public/styles.css`、`public/app.js` 和现有审阅页；不引入外部资产。`/api/admin/state` 与 `/api/health` 尚未提供 appliance、sing-box、rclone、MinIO、mc 的版本/更新检查合同，因此版本区必须显示“未接入检查”，不可声称已是最新。最小后续只读合同应返回固定组件名、当前固定版本、检查时间、最新稳定版（可空）、upgradeAvailable（可空）和检查错误码；更新动作仍只允许固定 tag 改动→构建→测试/健康检查→受控替换/回滚。

## 品牌与兼容边界

- 所有用户可见产品名使用 `Syncraft`，一次性设备凭据使用 `SyncKey`。
- 客户端只显示“同步 ID”和“同步内容”；不暴露仓库、bucket、prefix、远端目录、endpoint 或 rclone remote。
- SyncKey 是授权凭据；同步 ID 只表示共享内容，不能被表述为凭据。
- Sync ID 由管理员创建且全局唯一；冲突返回 `sync_id_unavailable`。服务端生成内部空间 ID 和存储目标，普通客户端只能显示当前 SyncKey 已授权空间。
- 客户端显示实际 Sync ID 依赖 Profile 或本地安全摘要携带该非敏感字段；原型不伪造此能力，属于待补齐的数据合同。
- 兼容实现保留 `tKey` 字段、`SFSC1-...` 编码、`sfsc://` URI、buildId、API 和错误码。页面不展示或解释这些旧标识，统一称为“SyncKey 导入码”。

## 字体

- UI：`"Segoe UI Variable", "Microsoft YaHei UI", "Segoe UI", sans-serif`
- 数字与代码：`"Cascadia Code", Consolas, ui-monospace, monospace`
- 正文 14px / 1.5；小字 12px；区块标题 16px；页面标题 24px。
- 按钮和标签使用 500 字重与 `0.02em` 字距；不使用 700+ 粗体。

## 布局

- 桌面最小目标 1280×720，核心工作区在 1440×900 最舒适。
- 全局侧栏 216px；顶部栏 48px；内容最大宽度 1440px。
- 基础间距 4px，常用间距 8 / 12 / 16 / 24 / 32px。
- 面板圆角 6px，按钮 5px，状态标签 999px；阴影只用于模态框和浮层。
- 客户端每屏最多一个强主操作；服务端允许密集表格但不允许卡片墙。

## 状态表达

- 正常：绿色圆点/文字，不使用整块绿色背景。
- 同步中：蓝灰信息色 + 进度条；动效仅使用低频脉冲。
- 警告：琥珀色，必须附带影响和下一步。
- 失败：绯红色，固定结构为“发生了什么 / 影响 / 下一步 / 错误码”。
- 离线：中性灰，不与失败混用。
- 协议不兼容：绯红色并阻止同步；兼容警告：琥珀色并要求确认。

## 组件规则

- 主按钮仅在当前主任务上使用青蓝色；每屏最多两处青蓝色可见用途。
- 危险按钮不与主按钮紧邻；清空、删除、镜像同步均使用页面内模态确认。
- 输入控件高度 34–38px，桌面点击目标至少 40px。
- 长路径一行省略，提供标题提示与复制操作；表格列不得被长路径撑开。
- 密钥默认显示为 `••••••••`，显示/复制必须是显式动作。
- 任何用户界面不得出现真实 SyncKey、Token、私钥、设备数据或本机路径。
