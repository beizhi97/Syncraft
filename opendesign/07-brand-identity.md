# SFSC 品牌身份方向

## 好看的标准

- 受众：普通 Windows 用户需要快速确认下一步，管理员需要持续扫描服务风险。
- 业务目标：让“本地文件与同步仓库之间正在发生什么”一眼可辨。
- 品牌气质：明亮、可靠、克制、技术准确，不像安全软件或云存储营销页。
- 信息密度：客户端中低密度，服务端高密度；品牌只在应用入口、侧栏和登录时出现。

## 推荐方向：文件传递轨迹

主符号使用一条上行与一条下行的折线轨迹，形成抽象文件轮廓。它表达双向传递，但不直接绘制云、盾牌、锁或通用链路。

字标使用 `SFSC`，Segoe UI Variable Semibold，0 至 -0.01em 字距。组合标为符号在左、字标在右；极小尺寸只保留符号。

## 探索路线

1. 双文件交换：最直观，适合首次导入页，但小尺寸细节较多。
2. 折页同步：强调文件夹，适合文档工具，但更接近传统存储产品。
3. 节点编排：适合管理员控制台，但对普通用户偏抽象。
4. 文件传递轨迹：推荐。紧凑、原创、适合客户端和服务端共用。

## 色彩与字体

- 深海军蓝 `#18324B`：默认字标和浅色界面符号。
- 青蓝 `#1479D1`：轨迹中的单一传递强调，不用于正文或多重装饰。
- 冷白 `#F5F8FC`：品牌底色与宽松留白。
- UI：Segoe UI Variable / Microsoft YaHei UI。
- 数字与标识元数据：Cascadia Code。

## 使用规则

- 浅色界面使用深海军蓝主轨迹和一处青蓝端点。
- 深色侧栏使用冷白主轨迹和一处青蓝端点。
- 不使用渐变、外发光、投影、描边放大或旋转动画。
- 不把成功、警告或失败状态色带入标识。
- 图标小于 20px 时保留两条轨迹，不附加字标。

## 资源选择

- 标识探索图用于对比四种符号语言，已排除云、盾牌和通用链路。
- 共享 CSS Token 负责跨客户端与服务端的一致色彩和尺寸。
- 不引入外部组件库或装饰素材，避免打破原生桌面工具的轻量和密度。

## 落地范围

本轮将推荐符号写入共享品牌标记，并在入口页显示完整组合标。后续如需安装包图标，应基于该符号输出 16、24、32、48、256px 的单色与双色位图版本。
