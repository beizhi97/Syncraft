# SFSC 设计系统

## 设计姿态

SFSC 是明亮、紧凑、可信的 Windows 同步工具。产品首屏直接呈现任务、状态和下一步，不使用营销文案、装饰插画、渐变背景或大面积品牌色。冷白工作面与青蓝操作色让客户端和服务端保持轻快一致；客户端优先可理解性，服务端优先信息密度。

## 字体

- UI：`"Segoe UI Variable", "Microsoft YaHei UI", "Segoe UI", sans-serif`
- 数字与代码：`"Cascadia Code", Consolas, ui-monospace, monospace`
- 正文 14px / 1.5；小字 12px；区块标题 16px；页面标题 24px。
- 按钮和标签使用 500 字重与 `0.02em` 字距；不使用 700+ 粗体。

## 布局

- 桌面最小目标 1280×720，核心工作区在 1440×900 最舒适。
- 全局侧栏 216px；顶部栏 48px；内容最大宽度 1440px。
- 基础间距 4px，常用间距 8 / 12 / 16 / 24 / 32px。
- 面板圆角 6px，按钮 5px，状态标签 999px；阴影只用于模态框和浮层。
- 客户端每屏最多一个强主操作；服务端允许密集表格但不允许卡片墙。

## 状态表达

- 正常：绿色圆点/文字，不使用整块绿色背景。
- 同步中：蓝灰信息色 + 进度条；动效仅使用低频脉冲。
- 警告：琥珀色，必须附带影响和下一步。
- 失败：绯红色，固定结构为“发生了什么 / 影响 / 下一步 / 错误码”。
- 离线：中性灰，不与失败混用。
- 协议不兼容：绯红色并阻止同步；兼容警告：琥珀色并要求确认。

## 组件规则

- 主按钮仅在当前主任务上使用青蓝色；每屏最多两处青蓝色可见用途。
- 危险按钮不与主按钮紧邻；清空、删除、镜像同步均使用页面内模态确认。
- 输入控件高度 34–38px，桌面点击目标至少 40px。
- 长路径一行省略，提供标题提示与复制操作；表格列不得被长路径撑开。
- 密钥默认显示为 `••••••••`，显示/复制必须是显式动作。
- 任何用户界面不得出现真实 T-key、Token、私钥、设备数据或本机路径。
